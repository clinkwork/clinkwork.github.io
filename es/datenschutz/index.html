Privacidad del sitio

Esta página explica cómo se tratan los datos cuando visitas el sitio de Clinkwork o contactas con soporte.

Este sitio

Aquí no hay analítica, píxeles publicitarios ni fuentes externas. GitHub Pages, el proveedor de alojamiento previsto, puede procesar datos técnicos como direcciones IP para ofrecer y proteger el sitio. Esto es independiente de la etiqueta de las apps «No se recopilan datos».

Política de privacidad de GitHub

Tus creaciones se quedan contigo

Los ajustes y, cuando estén disponibles, las creaciones guardadas se almacenan en tu dispositivo. Borra el almacenamiento local del sitio para eliminar los ajustes del navegador. Las máquinas compartidas viajan en el fragmento del enlace; Clinkwork no las sube a un servidor.

Fines y bases jurídicas

Los ajustes locales necesarios permiten prestar el servicio solicitado. Se prevé basar el alojamiento y la seguridad en intereses legítimos (RGPD, art. 6.1.f); el soporte en medidas precontractuales o contractuales cuando proceda (art. 6.1.b), o en intereses legítimos.

Contacto

Si contactas con soporte, la información que envíes se usa para responderte. No envíes contraseñas ni datos de pago.

Tus derechos y la conservación

Según las condiciones aplicables, puedes solicitar acceso, rectificación, supresión, limitación o portabilidad y oponerte al tratamiento. Puedes reclamar ante una autoridad de control.

Si contactas con el soporte, usamos los datos de tu mensaje solo para atender tu solicitud y los conservamos solo el tiempo que esto y las obligaciones legales de conservación requieran. Los ajustes guardados en tu navegador permanecen allí hasta que los borres. GitHub, como proveedor de alojamiento, determina cuánto tiempo se conservan los datos técnicos de acceso. Para ejercer tus derechos, contáctanos en la dirección indicada arriba.
