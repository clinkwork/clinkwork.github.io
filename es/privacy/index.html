Clinkwork / Privacidad de las apps

No se recopilan datos

Sin analítica ni cuentas. Clinkwork no recopila datos personales a través de Loop Machine o Forge. Los códigos permanecen en tu dispositivo salvo que decidas compartirlos.

Tus creaciones se quedan contigo

Los ajustes y, cuando estén disponibles, las creaciones guardadas se almacenan en tu dispositivo. Borra el almacenamiento local del sitio para eliminar los ajustes del navegador. Las máquinas compartidas viajan en el fragmento del enlace; Clinkwork no las sube a un servidor.

Servicios de Apple

Apple gestiona las compras en las ediciones iOS. Si usas Game Center, sus servicios procesan la información necesaria conforme a la política de privacidad de Apple.

Este sitio

Aquí no hay analítica, píxeles publicitarios ni fuentes externas. GitHub Pages, el proveedor de alojamiento previsto, puede procesar datos técnicos como direcciones IP para ofrecer y proteger el sitio. Esto es independiente de la etiqueta de las apps «No se recopilan datos».

Contacto
