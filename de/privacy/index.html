Clinkwork / Datenschutz der Apps

Keine Daten erfasst

Keine Analyse-Tools. Keine Konten. Clinkwork erhebt über Loop Machine und Forge keine personenbezogenen Daten. Loop-Codes bleiben auf deinem Gerät, sofern du sie nicht selbst teilst.

Deine Werke bleiben bei dir

Einstellungen und, soweit verfügbar, gespeicherte Werke bleiben auf deinem Gerät. Lösche den lokalen Websitespeicher, um Browsereinstellungen zu entfernen. Geteilte Maschinen stecken im Fragment eines Links; Clinkwork lädt sie nicht auf einen Server hoch.

Apple-Dienste

In den iOS-Versionen wickelt Apple Käufe ab. Wenn du Game Center nutzt, verarbeiten Apples Dienste die dafür nötigen Informationen gemäß Apples Datenschutzrichtlinie.

Diese Website

Hier gibt es keine Analysedienste, Werbepixel oder externen Schriftarten. Der vorgesehene Hoster GitHub Pages kann technische Anfragedaten einschließlich IP-Adressen verarbeiten, um die Website bereitzustellen und abzusichern. Das ist von der App-Angabe „Keine Daten erfasst“ zu unterscheiden.
