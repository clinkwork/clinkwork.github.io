Clinkwork / Confidentialité des apps

Aucune donnée collectée

Aucune analyse d’utilisation. Aucun compte. Clinkwork ne collecte pas de données personnelles via Loop Machine ou Forge. Les codes restent sur votre appareil, sauf si vous décidez de les partager.

Vos créations restent avec vous

Les réglages et les créations enregistrées, lorsque disponibles, restent sur votre appareil. Effacez le stockage local du site pour supprimer les réglages du navigateur. Les machines partagées voyagent dans le fragment d'un lien ; Clinkwork ne les envoie pas à un serveur.

Services Apple

Dans les éditions iOS, Apple gère les achats. Si vous utilisez Game Center, les services Apple traitent les informations nécessaires selon leur politique de confidentialité.

Ce site

Ce site n'utilise ni analyse d'audience, ni pixels publicitaires, ni polices externes. L'hébergeur prévu, GitHub Pages, peut traiter des données techniques, dont les adresses IP, pour fournir et sécuriser le site. Cela est distinct de la mention « Aucune donnée collectée » des apps.

Contact
