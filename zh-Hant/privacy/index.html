Clinkwork / App 隱私權政策

未收集資料

沒有使用分析，也無需帳號。Clinkwork 不透過 Loop Machine 或 Forge 收集個人資料。除非你主動分享，否則循環代碼始終留在你的裝置上。

作品留在你手中

設定以及已提供儲存功能的作品保存在你的裝置上。清除網站的本機儲存空間即可刪除瀏覽器設定。分享的機器包含在連結片段中，Clinkwork 不將其上傳至伺服器。

Apple 服務

iOS 版中的購買由 Apple 處理。如果你選擇使用 Game Center，Apple 服務將依其隱私權政策處理所需資訊。

本網站

本站不使用分析工具、廣告像素或外部字型。預計使用的託管服務 GitHub Pages 可能為提供和保護網站而處理包括 IP 位址在內的技術請求資料。這與 App 的「未收集資料」標籤不同。

網站隱私權

聯絡方式

聯絡支援時，你傳送的資訊將用於回覆請求。請勿傳送密碼或付款資訊。
