GitHub 隱私權聲明

作品留在你手中

設定以及已提供儲存功能的作品保存在你的裝置上。清除網站的本機儲存空間即可刪除瀏覽器設定。分享的機器包含在連結片段中，Clinkwork 不將其上傳至伺服器。

目的與法律依據

必要的本機設定用於提供你要求的服務。託管與安全擬依據合法利益（GDPR 第6條第1項f款）；支援在適用時依據契約前或契約措施（b款），否則依據合法利益。

聯絡方式

聯絡支援時，你傳送的資訊將用於回覆請求。請勿傳送密碼或付款資訊。

你的權利與保存期限

在適用條件下，你可要求存取、更正、刪除、限制處理或資料可攜，並可反對處理。你也可向監管機關申訴。

如果你聯絡支援，我們只會將你訊息中的資訊用於處理你的請求，並僅在處理請求及履行法定保存義務所需的期間內保存。儲存在你瀏覽器中的設定會一直保留在瀏覽器中，直到你將其刪除。技術存取資料的保存期間由託管服務商 GitHub 決定。如需行使你的權利，請透過上方地址與我們聯絡。
