Clinkwork / 앱 개인정보 처리방침

수집하는 데이터 없음

사용 분석과 계정이 없습니다. Clinkwork는 Loop Machine이나 Forge를 통해 개인정보를 수집하지 않습니다. 루프 코드는 직접 공유하지 않는 한 기기에만 남습니다.

작품은 내 기기에

설정과 저장 기능이 있는 경우의 작품은 기기에 저장됩니다. 브라우저 설정을 지우려면 사이트의 로컬 저장소를 삭제하세요. 공유 기계는 링크의 프래그먼트에 담기며 Clinkwork 서버에 업로드되지 않습니다.

Apple 서비스

iOS 버전의 구매는 Apple이 처리합니다. Game Center를 선택하여 사용하면 Apple 서비스가 개인정보 처리방침에 따라 필요한 정보를 처리합니다.

이 웹사이트

분석 도구, 광고 픽셀, 외부 글꼴을 사용하지 않습니다. 예정된 호스팅 업체 GitHub Pages는 사이트 제공과 보안을 위해 IP 주소 등 기술적 요청 데이터를 처리할 수 있습니다. 이는 앱의 ‘수집하는 데이터 없음’ 표시와 별개입니다.
