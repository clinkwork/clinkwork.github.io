Clinkwork / 应用隐私政策

未收集数据

没有使用分析，也无需账号。Clinkwork 不通过 Loop Machine 或 Forge 收集个人数据。除非你主动分享，否则循环代码始终留在你的设备上。

作品留在你手中

设置以及已提供保存功能的作品存储在你的设备上。清除网站的本地存储即可删除浏览器设置。分享的机器包含在链接片段中，Clinkwork 不将其上传至服务器。

Apple 服务

iOS 版中的购买由 Apple 处理。如果你选择使用 Game Center，Apple 服务将依其隐私政策处理所需信息。

本网站

本站不使用分析工具、广告像素或外部字体。计划使用的托管服务 GitHub Pages 可能为提供和保护网站而处理包括 IP 地址在内的技术请求数据。这与应用的“未收集数据”标签不同。

网站隐私

联系方式

联系支持时，你发送的信息将用于回复请求。请勿发送密码或付款信息。
