GitHub 隐私声明

作品留在你手中

设置以及已提供保存功能的作品存储在你的设备上。清除网站的本地存储即可删除浏览器设置。分享的机器包含在链接片段中，Clinkwork 不将其上传至服务器。

目的与法律依据

必要的本地设置用于提供你请求的服务。托管和安全拟依据合法利益（GDPR 第6条第1款f项）；支持在适用时依据合同前或合同措施（b项），否则依据合法利益。

联系方式

联系支持时，你发送的信息将用于回复请求。请勿发送密码或付款信息。

你的权利与保存期限

在适用条件下，你可请求访问、更正、删除、限制处理或数据可携，并可反对处理。你也可向监管机构投诉。

如果你联系支持，我们只会将你消息中的信息用于处理你的请求，并仅在处理请求及履行法定保存义务所需的期限内保存。保存在你浏览器中的设置会一直留在浏览器中，直到你将其删除。技术访问数据的保存期限由托管服务商 GitHub 决定。如需行使你的权利，请通过上方地址联系我们。
